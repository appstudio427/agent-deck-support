Getting started

Agent Deck works alongside Claude Code, Anthropic's command-line coding tool. You'll need:

  • A Mac with macOS 12 or later
  • Claude Code, installed separately
  • A Claude account (or, for Local mode, Ollama with a downloaded model)

Install Claude Code. Open Terminal, paste this line and press Return:

curl -fsSL https://claude.ai/install.sh | bash

Then type claude and press Return to sign in with your Claude account. You can also use the Let's get started checklist in Agent Deck, which copies the command for you.

Add a project. Click New project, then Browse…, and pick your project folder. Agent Deck adds its hooks there so it can follow your sessions. Your code isn't changed.

Start Claude. On the project's Claude tab, click Run in Terminal. The session appears in Topology as soon as you send your first prompt.

Common questions

Why does Claude run in Terminal instead of inside Agent Deck?

Apps from the Mac App Store run in Apple's App Sandbox, which doesn't allow them to host a terminal. Agent Deck opens a Terminal window for you and follows the session from there.

macOS asked whether Agent Deck may control Terminal

Click OK so Run in Terminal can open the window for you. If you clicked Don't Allow, turn it back on in System Settings › Privacy & Security › Automation › Agent Deck › Terminal. Without it, Agent Deck copies the command instead, and you can paste it into Terminal with ⌘V.

My session doesn't show up in Topology

Check that the project header says Hooks installed. If it doesn't, click Install hooks. Sessions started before the hooks were installed aren't tracked, so start a new one with Run in Terminal.

Resume or my own agents are missing

Agent Deck can only read your Claude folder (~/.claude) after you allow it. Go to Settings › Claude Code, click Allow access… next to Claude folder, and choose the folder that opens.

How do I use Local mode?

Install Ollama from ollama.com and download a coding model in Settings › Local models. Then switch a project from Anthropic to Local in its header. Local models run on your Mac and use no Claude tokens, but they're generally less capable than Claude.

Where is my data kept?

Everything stays on your Mac, inside Agent Deck's own app folder. See the privacy policy for details.
