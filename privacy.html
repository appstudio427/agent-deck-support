Privacy Policy

Agent Deck, by App Studio 427 · Effective November 6, 2026

Support support@appstudio427.com

The short version

Agent Deck doesn't collect, store or share any personal data. It has no account, no analytics, no advertising and no tracking. Everything it keeps stays on your Mac.

What Agent Deck stores, and where

To work, Agent Deck saves your projects, settings, change logs, agent map and recent session activity. It keeps these only on your Mac, inside its own app folder, and never sends them to us or anyone else. Deleting the app deletes this data.

Agent Deck reads and writes project folders and your Claude folder (~/.claude) only after you pick them in an Open dialog. In each project folder it adds Claude Code hook settings (.claude/settings.local.json), and when you choose to, copies files you upload into .agent-deck/uploads/.

Network connections

  • On your Mac only: Claude Code reports session activity to Agent Deck over a local connection (127.0.0.1). This never leaves your computer.
  • Local models: if you use Local mode, Agent Deck talks to Ollama at the address you set (by default, on your own Mac).
  • Custom endpoints: if you set one up, Claude Code connects to the endpoint you entered.
  • Links: some buttons open web pages, such as claude.com or ollama.com, in your browser.

App Studio 427 runs no servers that Agent Deck connects to.

Claude Code and other services

Agent Deck starts Claude Code, a separate tool made by Anthropic. Your prompts, code and account are handled by Claude Code and Anthropic under Anthropic's privacy policy, not by Agent Deck. The same applies to Ollama and any custom endpoint you choose to use.

Children

Agent Deck is a developer tool and isn't directed at children. It collects no information from anyone.
